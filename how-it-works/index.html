How it works

Four steps, and the third one is the product

Most backup tools stop after step two. A file that downloaded is not the same as a file that opens, and neither tells you what leaving would cost.

1. Run the platform’s own export, on a schedule

Exit Check does not invent a way out. It uses the export the platform already publishes and runs it every day, week or month, unattended.

2. Write the copy where you control it

A folder on your own disk, your own storage, your own NAS. Exit Check never holds the only copy of anything.

3. Open it, and say what is missing

Every structured file is parsed. Images are checked against their real bytes. Zero-byte files, nested archives and stranded metadata are reported by name, then compared with the platform item by item. Try it on the Check an export page.

4. Answer one question, in one sentence

Leaving this service today would take about N hours and $N, and you would leave behind these things. That sentence is the entire output.

What it deliberately is not

  • Not a model. The exit cost is arithmetic over fields you can read.
  • Not a migration tool. Moving your data is a different product. This one only measures.
  • Not another home for your data. The copy goes to storage you own. Exports checked here are read in your browser, never uploaded.
  • Not a dashboard to visit. Silent until a number moves, then it sends one sentence.
